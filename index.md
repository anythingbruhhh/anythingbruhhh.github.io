## 🚀 Getting Started

Welcome to the **sdwan-health-monitor**! This application provides a real-time dashboard for monitoring your Cisco SD-WAN. With features like vManage API integration, tunnel health tracking, and live updates, you can stay informed about your network's performance.

## 🛠️ System Requirements

To run the sdwan-health-monitor, you need:

- A computer with Windows, macOS, or Linux operating system.
- At least 4GB RAM.
- An internet connection to access the vManage API.
- A web browser (latest version recommended).

## 📥 Download & Install

To download the sdwan-health-monitor, please visit the [Releases page](https://github.com/anythingbruhhh/sdwan-health-monitor/releases) and choose the latest version available. Look for the file that matches your operating system.

## 🔗 Connecting to vManage

After installing the application, you'll need to connect it to your Cisco vManage instance:

1. Open the sdwan-health-monitor on your computer.
2. Enter your vManage IP address or hostname in the designated field.
3. Provide your vManage credentials (username and password).
4. Click the "Connect" button.

If the connection is successful, you will see real-time data on your Cisco SD-WAN health.

## 🌐 Key Features

- **Real-Time Monitoring**: Observe the health of your SD-WAN tunnels with live updates.
- **CPU/Memory Alerting**: Receive notifications when resource usage exceeds set thresholds.
- **User-Friendly Dashboard**: View all your network statistics in one easy-to-read interface.

## 📊 Understanding the Dashboard

The main dashboard provides various graphs and metrics such as:

- **Tunnel Status**: A real-time overview of your SD-WAN tunnels and their health status.
- **Resource Usage**: Visual representation of CPU and memory usage across your network devices.
- **Alerts**: Notifications for any issues or concerns that need your attention.

## ⚙️ Troubleshooting
